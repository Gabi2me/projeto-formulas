# Projeto formulas
Aplicação desenvolvida com conceitos de React por meio do Vite para o cálculo de fórmulas de matemática, física e química.
Tem como objetivo disponibilizar cálculos simples de fórmulas estudadas no segundo ano do ensino médio, exibidas na página inicial.
# Fórmulas
Densidade (d = m / v)

Calcula a densidade de um corpo a partir da massa e do volume.

Velocidade Média (v = d / t)

Determina a velocidade com base na distância percorrida e no tempo.

Área do Trapézio (A = (B + b) * h / 2)

Calcula a área utilizando base maior, base menor e altura.

Cada fórmula possui seu próprio componente e uma breve explicação.

# Ambiente de desenvolvimento
Foi necessário instalar o Node.js na máquina para gerenciar as dependências do projeto. Após isso, o projeto React foi criado utilizando o Vite. A aplicação foi executada localmente e acessada por meio de um endereço localhost no navegador.

# Detalhes técnicos
Linguagens: HTML, CSS e JS.

Estrutura: pastas, sub-pastas e componentes de inicialização com uma página inicial que centraliza as fórmulas.

Componentes: Densidade.jsx, VelocidadeMedia.jsx e AreaTrapezio.jsx.
